C Drive Cleaner

一款轻量、完全离线、追求极致的 Windows C 盘空间清理工具，由 Batch 和 PowerShell 混合编写。

版本: 2.8
适用平台: Windows 7/8/10/11
许可证: MIT (详见 LICENSE 文件)

简介

您是否经常为 C 盘空间不足而烦恼? C Drive Cleaner 是一个开源的批处理工具箱，无需安装任何第三方软件，即可深度清理系统临时文件、浏览器缓存、Windows 更新残留等，有效释放磁盘空间。

功能特性

- 一键快速清理: 全自动清理常用垃圾位置，适合普通用户。
- 高级自定义模式: 逐项选择要清理的内容，危险操作（如删除系统还原点）会显示醒目的红色警告。
- 磁盘空间查看: 输入盘符即可查看总容量、已用空间和剩余空间。
- 大文件查找（多线程）: 利用 PowerShell 多线程并发扫描，快速定位 C 盘中的大体积文件，支持自定义大小阈值。

安全警告

请在使用前务必备份重要数据。

1. 高级模式中的“删除系统还原点”和“清理补丁缓存”属于高风险操作，可能导致系统无法回滚或无法卸载特定更新，请谨慎使用。
2. 清理“安全日志(Security)”可能会影响部分安全审计软件，请根据实际环境决定是否执行。

快速开始

1. 从本仓库的 Releases 页面下载最新版本的“C Drive Cleaner v2.8.bat”文件。
2. 右键单击该文件，选择“以管理员身份运行”（此步骤必须执行，否则无法清理系统目录）。
3. 根据屏幕菜单提示输入对应的数字即可执行相应功能。

系统依赖

- Windows 7 及以上版本（需内置 PowerShell 环境，系统默认自带）。
- 管理员权限（运行时自动请求）。
